# ระบบแจ้งซ่อมบำรุงออนไลน์ โรงพยาบาลโคกศรีสุพรรณ (KSP Repair System)

โปรเจคปรับปรุงและพัฒนาใหม่ด้วย **Node.js + Express + SQLite (better-sqlite3)** จากระบบแจ้งซ่อมบำรุงเดิม (`comsystem` PHP/MySQL) โดยคงความสามารถเดิมทั้งหมด รองรับการเพิ่ม/แก้ไข/ลบข้อมูลใหม่ และมีสคริปต์โอนย้ายข้อมูลเก่าจากฐานข้อมูล MySQL เดิมให้ใช้งานร่วมกับระบบใหม่ได้อย่างสมบูรณ์

## คุณสมบัติหลัก
- **รายการแจ้งซ่อมบำรุง**: ค้นหา กรองตามเดือน/ปี พ.ศ./สถานะ/ประเภทซ่อม แสดงรายละเอียดใบแจ้งซ่อม และสั่งพิมพ์ใบแจ้งซ่อม/ตารางแจ้งซ่อม
- **บันทึกแจ้งซ่อมบำรุง**: รองรับทั้งหน่วยงานภายในโรงพยาบาล และหน่วยงานภายนอก (ใน CUP)
- **ระบบสิทธิ์ผู้ใช้งาน**: ผู้ใช้งานทั่วไป (`user`) และเจ้าหน้าที่/ช่างผู้ดูแลระบบ (`adminn`) โดยใช้บัญชีเดิมจากตาราง `personaldata`
- **จัดการงานซ่อม (สำหรับช่าง)**: มอบหมายช่างผู้รับผิดชอบ อัปเดตสถานะ (`รอตรวจสอบ`, `กำลังดำเนินการ`, `เสร็จเรียบร้อยแล้ว`, `ยกเลิก`) บันทึกค่าใช้จ่ายและการแก้ไขปัญหา
- **รายงานสรุป**: สรุปจำนวนงานและค่าใช้จ่ายแยกตามหน่วยงาน ประเภทซ่อม ช่างผู้รับผิดชอบ และสถานะ
- **จัดการข้อมูลหลัก (CRUD)**: เพิ่ม/แก้ไข/ลบ ประเภทรายการซ่อม (`room`), ข้อมูลช่าง (`equip`), หน่วยงาน (`unit_all`), และผู้ใช้งาน (`personaldata`)
- **สถิติลดการใช้กระดาษ**: คำนวณจำนวนแผ่นกระดาษ ค่าใช้จ่าย และ GHG ที่ลดได้

## การติดตั้งและใช้งาน
```bash
npm install
cp .env.example .env
# โอนย้ายข้อมูลเก่าจากฐานข้อมูล MySQL เดิม (แปลงรหัสภาษาไทย TIS-620/UTF-8 อัตโนมัติ)
npm run migrate
# เริ่มทำงานเซิร์ฟเวอร์
npm start
```

เปิดใช้งานได้ที่ `http://localhost:3530` (หรือพอร์ตที่กำหนดใน `.env`)
